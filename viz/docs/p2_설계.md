> **상태: 최신 (2026-10-09)**
> 기준 세대 G4 — Observed MAA EDF · `seoul_links.parquet` · heating_2026.csv(993행)
> 상위 문서: `viz/README.md`

확정 수치 (2026-10-09 재산출)
- 위험군 골목길 **1,395.6 km / 33,650구간**
- └ 열선 보호 **56.5 km / 1,137구간 (4.05%)**
- └ 비보호 **1,339.1 km / 32,513구간 (95.95%)**
- 일반 도로(배경) 135,326구간

## 0. 전달할 메시지

> 위험군 골목길은 **1,395.6 km**인데 열선이 덮는 급경사 구간은 **56.5 km(4.05%)**다.
> 지도에서 보호 구간이 **거의 보이지 않는 것** 자체가 결론이다.

좌측은 "얼마나 깔았나", 우측은 "그런데 얼마나 못 덮었나"를 맡는다.


### 추가 필요 — 선 형상

`seoul_links.parquet`에는 **링크 중점만** 들어 있다. 지도를 점으로 찍으면 도로망으로 안 읽힌다.
선을 그리려면 좌표열이 필요한데, 원본 `road_links.geojson`은 **92 MB**라 매번 읽기엔 무겁다.

다행히 좌표점은 **총 805,614개**(링크당 평균 4.5점, 32%는 2점)뿐이라 가볍게 뽑을 수 있다.

```
data/seoul_link_geom.parquet
  link_id : int32
  lons    : list<float32>
  lats    : list<float32>
```

예상 5~8 MB. `scripts/build_seoul_dataset.py`에 산출 단계를 하나 추가한다.

## 2. 라이브러리

| 용도 | 선택 | 이유 |
|---|---|---|
| **발표자료 PNG** | **matplotlib `LineCollection`** | 180k 선을 한 번에 그린다. 루프보다 수십 배 빠르고, 선 굵기·색·알파를 배열로 일괄 지정할 수 있다. 300 dpi 벡터급 출력이 나와 슬라이드에 바로 들어간다 |
| Streamlit 지도 | `pydeck` `PathLayer` | 앱에 이미 쓰고 있고 줌·툴팁이 붙는다 |
| 막대그래프 | `altair` | `delta_lab.py`에서 이미 쓰는 중. 일관성 |
| 좌표 투영 | 없음 (등장방형 근사) | 서울 범위에서 `x = lon × 88322`, `y = lat × 111320`이면 충분. 기존 파이프라인과 동일 상수 |

**geopandas·folium은 쓰지 않는다.** 전자는 의존성이 무겁고(GDAL), 후자는 타일 서버를 타서 PNG 품질이 들쭉날쭉하다. 지금 필요한 건 배경 지도 없는 **도로망 실루엣**이라 matplotlib이면 충분하다.

## 3. 색상 — 전 산출물 통일

`utils/theme.py`를 단일 출처로 두고 지도·막대·표가 전부 참조한다.

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| **현행 열선 / 보호됨** | `#1F6FEB` 파랑 | 기존 설치 구간, 막대의 설치분 |
| **제안 선정** | `#E0674A` 코랄 | MILP 해 (p11~12) |
| **경계·하류 위험** | `#C23B22` 진한 적 | 경계쌍, 하류 구간 (p5) |
| **위험군 미보호** | `#B9C2CE` 회색 | 비보호 위험군, 막대의 미설치분 |
| 지도 배경(일반 도로) | `#E8EBEF` 연회색 | 위험군 아닌 도로 |
| 자치구 경계 | `#9AA5B1` | 얇은 실선 |
| 강조(성북구) | `#1F3A5F` 네이비 | 테두리·라벨 |

**규칙**
1. 파랑 = 언제나 현행/보호, 코랄 = 언제나 제안. 지도·차트·표 전부 동일
2. 경사 농도가 필요하면 기존 `SLOPE_COLORS` 4등급만 (연속 그라데이션 금지)
3. 캡션은 `구분 · 모집단 · 기준 · 출처파일` 4요소 고정
4. 비율은 분모를 캡션에 명시
5. 위첨자 글리프가 Noto CJK에 없으므로 `p = 6.9e-135` 표기로 통일

## 4. 그림1 — 레이어 구성

아래에서 위로 그린다. **순서가 메시지를 만든다.**

| 순서 | 레이어 | 대상 | 색 | 선 굵기 | 알파 |
|---|---|---|---|---|---|
| 1 | 일반 도로 | 위험군 아닌 링크 | `#E8EBEF` | 0.15 | 0.5 |
| 2 | 자치구 경계 | 25개 폴리곤 | `#9AA5B1` | 0.6 | 0.8 |
| 3 | **위험군 미보호** | 골목길 ∩ 경사≥5.56% ∩ 열선없음 | `#B9C2CE` | **0.45** | 0.9 |
| 4 | **위험군 보호** | 골목길 ∩ 경사≥5.56% ∩ 열선 | `#1F6FEB` | **1.6** | 1.0 |

**보호 구간을 일부러 3.5배 굵게 긋는다.** 실제 비율(4.05%)대로 그리면 아예 안 보여서 그림이 죽는다. 굵게 그려도 여전히 성글게 보이는 것이 핵심이고, 캡션에 "선 굵기는 가독성을 위해 과장했으며 실제 연장 비율은 4.05%"라고 밝히면 정직성도 지킨다.

**인셋**: 우하단에 성북구 확대(위험군 연장 1위 138,770 m, 커버리지 19위). 전역에서 안 보이는 패턴을 한 번 더 확인시킨다.

**수치 박스** (좌상단)
```
위험군 골목길   1,395.6 km
└ 열선 보호        56.5 km  (4.05%)
└ 비보호        1,339.1 km  (95.9%)
```

## 5. 그림2 — 자치구별 위험군 커버리지

수평 막대 25개, 커버리지 내림차순. 성북구 막대만 네이비 테두리 + 라벨.

- x축: 커버리지(%) — `위험군_5.56pct_25gu.csv`의 `커버리지`
- 중앙값 **10.29%** 세로 점선
- 각 막대 끝에 위험군 연장(km) 작게 병기 → **"위험군이 큰 구일수록 막대가 짧다"**가 눈에 들어온다
- 캡션에 ρ=−0.719 (p=0.0001) 명시

> 성북구: 위험군 연장 1위(138,770 m)인데 커버리지 19위(8.90%)

### 보조 — 연도별 누적 연장

좌측 하단 작은 선그래프. `heating_2026_normalized.csv`
2020년 29건 → 2025년 255건(8.8배), 누적 148,433 m.
"많이 깔긴 했다"를 먼저 인정하고 우측에서 뒤집는 구조.

## 6. 구현 순서

1. `scripts/build_seoul_dataset.py`에 `seoul_link_geom.parquet` 산출 추가
2. `utils/theme.py` 신설 — 색·캡션 헬퍼 (`utils/geo.py`의 기존 상수 이전)
3. `scripts/fig_p2_coverage_map.py` — 그림1 PNG (16:9, 300 dpi)
4. `scripts/fig_p2_gu_coverage.py` — 그림2 막대 + 연도별 보조
5. Streamlit `📤 발표자료 내보내기` 탭에 두 그림 미리보기 연결

1~4가 끝나면 p2는 완성이고, 같은 `theme.py`로 p5 경계 지도와 p11 선정 지도도 바로 이어서 만들 수 있다.

## 7. 주의

- **선 굵기 과장은 반드시 캡션에 밝힌다.** 안 밝히면 "그림이 과장됐다"는 지적이 나온다
- 위험군 정의(경사 ≥ 5.56%, 골목길)를 그림 안에 넣는다. 다른 장의 2% 기준과 혼동 방지
- 커버리지는 **느슨 기준(열선 전체 ÷ 위험군)**을 쓴다 — `위험군_5.56pct_25gu.csv`가 그 기준이고 중앙값 10.29%도 거기서 나왔다. 엄격 기준(4.05%)은 본문 수치로만 쓰고 지도·막대는 느슨 기준으로 통일. **한 장에 두 기준을 섞지 않는다**
