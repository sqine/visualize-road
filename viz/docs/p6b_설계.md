## 0. 쪽 구성

근거가 셋이므로 패널도 셋이다. p7과 같은 3단 구성.

```
(a) 구릉지다          20개 행정동 산점도 — 급경사 비율 × 급경사 골목길 수
(b) 이어져 있다        4개동 인접 그래프 — 정릉2동 허브 사슬형
(c) 지정에서 소외됐다  보유 38.9% vs 지정 20.0% 대비 막대
```

읽는 순서: **위험이 크고(a) · 하나의 망이고(b) · 그런데 안 돌봐진다(c).**
(b)가 가운데 오는 이유는 경사 하류 누적위험이 **연결된 망**에서만 정의되기
때문이다. 규모만으로 뽑으면 (b)가 깨진다 — 그 반례가 패널 (b)의 주석이다.

## 2. 패널 (a) — 구릉지다

**x = 골목길 중 급경사 비율(%)** · **y = 급경사 골목길 수**

두 축을 쓰는 이유: 어느 한쪽만 보면 다른 조합이 뽑힌다. 이것이 M4 §4-1에서
기각된 가설들의 내용이다.

- **비율만 보면** 돈암1동(62.6%)·돈암2동(62.5%)이 1·2위지만 각각 62개·60개뿐이다
- **규모만 보면** 장위1동(295개, 3위)·정릉4동(237개, 4위)이 들어오는데
  장위1동은 성북구 동쪽 끝으로 **정릉권과 떨어져 있다** → (b)가 깨진다

4개동은 **두 축에서 동시에 상위**인 집합이다. 정릉2동(52.0% · 207개),
정릉3동(46.4% · 341개), 성북동(59.0% · 625개), 돈암2동(62.5% · 60개).

> **돈암2동을 변호한다.** 급경사 골목길 수로는 20개동 중 18위(60개)다. 들어온
> 이유는 **비율 2위(62.5%)**이면서 **정릉2동·성북동과 직접 연결**(36·13 엣지)되기
> 때문이다. 규모 기준만으로는 뽑히지 않는다는 점을 숨기지 않는다 — M4 §4-10 한계2.

### 표현

- 4개동: `PROPOSED` 코랄 채움 + 동명 라벨
- 나머지 16개동: `UNPROTECTED` 회색, alpha 0.55. 장위1동만 `BOUNDARY` 테두리로
  "규모는 크나 떨어져 있다"를 표시하고 (b)의 주석과 짝지음
- 점 크기 ∝ 링크수 (동 규모) — 돈암2동이 작은 점임을 보이게 한다
- 사분면 보조선: 급경사 비율 중앙값, 급경사 골목길 수 중앙값 (점선, 연한 회색)

## 3. 패널 (b) — 이어져 있다

4개 노드를 **실제 지리 좌표**(동 경계 중심)에 놓고, 엣지 굵기 ∝ 연결 엣지 수.

```
정릉3동 ──25── 정릉2동 ──36── 돈암2동
   └────6──── 성북동 ──13────┘
             (정릉2–성북 7)
정릉3동 ─ 돈암2동 : 0  (연결 없음)
```

**읽는 법**: 네 동이 서로 다 맞닿은 덩어리가 **아니다.** 정릉2동이 허브이고
정릉3동과 돈암2동은 서로 직접 닿지 않는다. 그래도 **하나의 연결 성분**이므로
상류→하류 경로가 집합 안에서 끊기지 않는다. 그것이 필요 조건의 전부다.

### 응집도 수치를 같이 보여준다

노드 그림만으로는 "이게 응집된 건가"를 판단할 수 없다. 오른쪽 아래에 작은
가로 막대로 E-I index 비교를 넣는다 — 무작위 800조합(평균 −0.8830) 대비
대상4동 −0.9425가 **상위 1.4%**임을, 그리고 **정릉권 1~4동이 더 응집(0.6%)**
한다는 사실을 함께 적는다.

> **유일 최적해가 아니라고 그림에서 말한다.** 정릉권 1~4동은 응집도가 더 높고
> 대상 4개동은 급경사 골목길이 **39.6% 많다**(1,233 vs 883). 응집도↔규모
> 트레이드오프이고 대상 4개동은 균형점이라는 문장을 각주로 고정한다.

**기각한 대안**: 20개동 전체 인접 그래프에 4개동만 색칠하는 안. 노드 20개·엣지
수십 개가 되면 사슬형 구조가 안 읽힌다. 핵심은 **4개동 내부 위상**이므로
4개만 그린다. 대신 (a)에서 장위1동을 표시해 "떨어진 동"의 존재를 알린다.

## 4. 패널 (c) — 지정에서 소외됐다

누적막대 2개를 위아래로 놓는다. 분모는 **성북구 20개 행정동 합계**다.

| | 4개동 | 나머지 16개동 | 4개동 몫 |
|---|---|---|---|
| 급경사 골목길 | 1,233 | 1,937 | **38.9%** |
| 결빙취약구간 지정 | 6 | 24 | **20.0%** |
| (참고) 링크수 | 3,036 | 9,724 | 23.8% |
| (참고) 열선 매칭 | 33 | 76 | 30.3% |

**위험의 38.9%를 안고 지정은 20.0%만 받는다.** 면적 대리값인 링크수가 23.8%
이므로 위험은 **면적 대비 1.63배 집중**된 반면 지정은 면적 몫에 못 미친다.

> **정릉2동은 0건이다.** 급경사 골목길 207개(5위)를 안고도 결빙취약구간 지정이
> 하나도 없다. 정릉4동(237개)이 3건, 성북동(625개)이 2건인 것과 비교해도
> 지정이 규모를 따라가지 않는다. 패널 (c)에 이 한 줄을 주석으로 박는다.

### 보고서 §8 수치를 정정한다

| 항목 | 보고서 §8 현재 | 데이터 재산출 | 조치 |
|---|---|---|---|
| 4개동 위험 몫 | "위험군의 **42.3%**" | 급경사 골목길 **38.9%** | 38.9%로 교체. 42.3%는 분모가 다른 구세대값 |
| 결빙 지정 | "28건 중 **7건(25%)**" | 30건 중 **6건(20.0%)** | 20.0%로 교체 |
| 위험군 비율 | 성북동 69.9% · 정릉3동 52.2% · 구평균 58.1% | 성북동 **49.2%** · 정릉3동 **32.1%** | §8은 **경사 2%↑** 기준, 데이터 파일은 **5.56%↑** 기준. 그림은 5.56% 기준만 쓰고 캡션에 명시 |
| z값 | z=−1.86 | 재산출 필요 | 그림에 쓰지 않음 (비율 대비만 제시) |

그림은 **전부 `seongbuk_dong_stats.csv` 값만** 쓴다. 보고서 문장은 별도로 고친다.

## 4-1. 글자 크기

`theme.py`에는 `TS_MAIN`(13.5) · `TS_PANEL`(12.2) 두 개뿐이고 **본문 크기 상수는
없다.** 쪽별 스크립트가 각자 숫자를 적는다. p7 기준으로 맞춘 바닥값은 다음과 같다.

| 역할 | pt |
|---|---|
| 전체 제목 | `T.TS_MAIN` 13.5 |
| 패널 제목 | `T.TS_PANEL` 12.2 |
| 핵심 수치 | 13.0 |
| 축 라벨 · 눈금 라벨 | 9.8 |
| 동명 라벨 | 9.6 |
| 주석·보조 설명 | 8.4 ~ 9.2 |
| 캡션 | 8.4 |

**8.4pt 미만을 쓰지 않는다.** 2026-10-11 p8의 E-I 표(7.8pt)와 중앙값·분모 라벨
(8.2pt)을 8.4pt로 올리고 E-I 상자 높이를 0.235 → 0.255, 행 간격을 0.042 → 0.046
으로 늘렸다. 상수화는 하지 않았다 — 패널 밀도가 쪽마다 달라 일괄 적용하면 넘친다.

## 5. 색·캡션

| 역할 | 색 | 상수 |

| 4개동 (제안 대상) | 코랄 | `PROPOSED` |
