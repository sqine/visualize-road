화살표는 상류 링크 중점 → 하류 링크 중점.

**붉은 반투명 원(7)**이 "열선이 끝나는 자리에 얼마나 큰 위험이 남는가"를 면적으로
보여 준다. 반지름이 아니라 **면적**이 노출에 비례하도록
`s = 240 + 820 × 하류노출/최댓값`로 잡았고, **두 패널의 기준을 맞추려고
확대 패널도 전체 최댓값(`expo_max`)으로 정규화**한다 — 그래야 (b)의 원을
(a)의 원과 같은 자로 읽을 수 있다. 원은 ▼ 아래(zorder 6)에 깔아 표식을 가리지 않는다.

## 3. 인셋 — 확대 1곳

> ⚠️ **설계안과 구현이 다르다.** 아래는 **권장(B10)**이고, `fig_p5_boundary_map.py`는
> **하류 노출이 가장 큰 경계쌍**(`b.하류노출.idxmax()` → **B16**, 노출 25.5 · 낙차 2.6 m)을
> 자동으로 잡아 확대한다. 그래서 확대 패널 라벨도 "최대 **노출** 경계쌍"이다
> (이전 "최대 경계쌍"은 낙차 최대(B01, 25.0 m)로 오독될 소지가 있어 고쳤다).
> B10으로 고정할지 지금처럼 자동 선택할지는 미정 — **발표 직전에 하나로 정한다.**

**권장: B10 (정릉2동)**

| 항목 | 값 |
|---|---|
| 상류(열선) 경사 | **2.08%** |
| 하류(미설치) 경사 | **16.00%** |
| 낙차 | 4.82 m |
| 하류 위험 | 0.776 |
| 하류 통행 | 25.77 |
| 하류 연장 | 57.0 m |

**왜 B10인가** — 상류가 2.08%로 완만한데 하류가 16.00%로 **7.7배 급하다.**
"완만한 곳에 열선을 깔고 그 아래 급경사를 비워 둔" 구조가 한눈에 보인다.
하류 연장 57 m로 그리기에 충분하고, 통행 25.77로 노출도 있다.

**대안**
- **B15** — 상류 2.33% → 하류 **23.01%** (9.9배, 위험 1.000). 대비는 더 크나 하류 연장 19.7 m로 짧아 그림이 작다
- **B01** — 낙차 **24.96 m**로 최대. 극적이나 하류 통행 3.55로 낮아 "위험" 논지가 약하다
- **B16** — 하류 통행 **47.76**로 최대. 낙차 2.62 m로 작아 고도차 표기가 밋밋하다

### 인셋 표기 요소

1. **열선 구간** — 파랑 굵은 선 + `열선 설치` 라벨
2. **물 흐름 방향** — 상류→하류 곡선 화살표, `theme.BOUNDARY`,
   중간에 💧 대신 `융설수` 텍스트 (이모지는 폰트 미지원)
3. **고도차** — 양 끝에 `z = ○○ m` 라벨, 사이에 `Δz = 4.82 m` 세로 치수선
4. **경사 대비** — `상류 2.08%` / `하류 16.00%` 를 각 구간 옆에
5. **하류 위험** — `P(미끄러짐) = 0.776` 를 하류 구간 아래

### 배치
메인 지도 **우하단**에 인셋 축(`inset_axes`), 메인에서 해당 위치를
`theme.ACCENT` 사각형으로 표시하고 인셋과 연결선.

```
규모·유의성은 서울 전역(경계 1,205곳, 생성률 75.8%)으로 주장하며,
4개동은 구성의 실재를 확인하는 사례다.
```

> ⚠️ 4개동 단독 통계(하류 경사 10.86% vs 일반 7.11%, p=0.096)는 **표본이 작아
> 유의하지 않다.** 본문 주장은 전역 수치(1.82배, p=6.9e-135)로 하고,
> 이 그림은 **"그 구성이 실제로 존재한다"**는 역할만 맡는다.

## 6. 재현

```bash
cd streamlit_app
python3 - <<'EOF'
import sys; sys.path.insert(0,'.')
from utils import milp as M
from utils.risk import obs_risk
import pandas as pd
G = M.load_graph()
heat = set(M.installed_links(G, golmok_only=False))
rows = []
for u in heat:
    zu = G.nodes[u].get('z')
    if zu is None: continue
    for v in G.neighbors(u):
        if v in heat: continue
        zv = G.nodes[v].get('z')
        if zv is None or zu - zv < M.H_MIN: continue
        rows.append(dict(상류=u, 하류=v, 낙차m=round(zu-zv, 2)))
print(len(rows), '쌍')
EOF
```
