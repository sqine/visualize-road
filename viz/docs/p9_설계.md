### 레이아웃 함정 두 가지 (다음에 고칠 때 반드시 확인)

1. **설명 두 줄은 `shape` 요소다.** `update_text_anchoring`이 먹지 않고
   (`Cannot update anchoring of a non-text element`) 텍스트가 상자 안에서
   **세로 중앙 정렬**된다. 그래서 상자 `top`을 원하는 글자 위치보다
   `(상자높이 − 글자높이)/2` 만큼 **위로** 올려야 한다.
   (1) 설명은 h 55 · 1줄이라 −14, (2) 설명은 h 126 · 3줄이라 −22.
2. **줄 수 제약**: 21pt·폭 1140에서 한 줄 ≈ 54자. (2) 설명은 **3줄 이내**로
   유지해야 ※ 줄과 겹치지 않는다. 늘어나면 회색 박스 높이부터 키운다.

## 3. 왜 선형 완화로 두는가

`bᵢⱼ` 는 패널티 항에만, 음의 계수로 들어간다. 최대화 문제이므로 해가 하한까지
밀어내려 `bᵢⱼ* = max(0, xᵢ − xⱼ)` 가 된다. `x` 가 0/1 이면 이 값도 0/1 이다.

> 508개를 전부 이진으로 선언하면 분기한정 트리가 2^508 배로 커진다. 선형
> 완화로 두면 LP 완화가 타이트해져 CBC 가 현실 시간에 푼다.

## 4. 경계쌍 D 집계 — 재현

```python
from utils import milp
G = milp.load_graph(); C = set(milp.candidates(G))
D = [(i, j) for u, v in G.edges() for i, j in ((u, v), (v, u))
     if G.nodes[i]["z"] - G.nodes[j]["z"] >= milp.H_MIN]
len(C)                                  # 847  후보 구간
len(D)                                  # 718  낙차 2m 이상 유향쌍
sum(1 for i, j in D if i in C)          # 508  그중 상류가 후보 = D
sum(1 for i, j in D if i in C and j in C)      # 415  하류도 후보
sum(1 for i, j in D if i in C and j not in C)  #  93  하류 고정(xⱼ ≡ 0)
```

전체 그래프: 노드 1,190 · 엣지 1,775 (4개동).
